## About
This is the repository contains my personal github.io website.

## Built With
* **HTML5** - For the structure and content.
* **CSS3** - For the styling and layout.
* **JavaScript** - For interactive elements and behavior.

## Running Locally
To run this project on your computer:

1. Clone the repository:
   ```bash
   git clone https://github.com/nickrezuke/nickrezuke.github.io.git
   ```
2. Open the project folder in your favorite code editor (like VS Code).
3. Open `index.html` in your browser or use a live server extension to view it.
